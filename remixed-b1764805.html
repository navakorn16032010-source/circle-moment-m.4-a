⏱ ความสัมพันธ์ ω, f, T
ω = 2π/T = 2πf
ω (โอเมก้า) คือมุมที่หมุนได้ต่อวินาที หน่วย rad/s
ถ้าหมุน 1 รอบ = 2π เรเดียน ใช้เวลา T วินาที → ω = 2π/T
✅ ใช้เมื่อรู้คาบ T หรือความถี่ f แล้วอยากได้ ω
f = 1/T  |  T = 1/f
f คือจำนวนรอบต่อวินาที, T คือเวลาต่อ 1 รอบ
ตัวอย่าง: f = 2 Hz → หมุน 2 รอบ/วินาที → T = 0.5 วินาที/รอบ
✅ ใช้แปลงระหว่าง f กับ T
v = rω = 2πr/T = 2πrf
ความเร็วเชิงเส้น v = รัศมี × ความเร็วเชิงมุม
ยิ่งรัศมีมาก หรือหมุนเร็ว → v มากขึ้น
✅ ใช้หา v จาก r และ ω
⭕ ความเร่งและแรงสู่ศูนย์กลาง
a꜀ = v²/r = ω²r
ความเร่งสู่ศูนย์กลาง — ชี้เข้าหาศูนย์กลางเสมอ
ทิศทางเปลี่ยนตลอด แต่ขนาดคงที่ (ถ้า v คงที่)
✅ ใช้หาความเร่ง เมื่อรู้ v และ r
F꜀ = mv²/r = mω²r = ma꜀
แรงสู่ศูนย์กลาง — ต้องมีแรงนี้เพื่อให้วัตถุเดินวงกลม

✅ ใช้หาแรงที่ทำให้วัตถุเดินวงกลม
🔴 Conical Pendulum (ลูกตุ้มวงกลม)
วัตถุแขวนเชือกแล้วหมุนเป็นวงกลม เชือกทำมุม θ กับแนวดิ่ง
แรงที่กระทำ: แรงโน้มถ่วง mg ↓ + ความตึงเชือก T เฉียงขึ้น
r = L·sinθ
รัศมีวงกลม = ความยาวเชือก × sin(มุม)
ทำไมต้อง sinθ? เพราะ r คือระยะแนวนอน และเชือกทำมุม θ กับแนวดิ่ง → ด้านตรงข้ามมุม θ คือแนวนอน → sin
✅ ใช้หารัศมีจาก L และ θ
T·cosθ = mg  →  T = mg/cosθ
แนวดิ่ง: แรงขึ้น = แรงลง
ทำไมต้อง cosθ? ความตึงเชือก T เฉียง → ส่วนที่เป็นแนวดิ่งคือ T·cosθ (ด้านชิดมุม θ → cos)
✅ ใช้หาความตึงเชือก
T·sinθ = mv²/r  →  F꜀ = T·sinθ
แนวนอน: ส่วนแนวนอนของ T = แรงสู่ศูนย์กลาง
ทำไมต้อง sinθ? T·sinθ คือส่วนแนวนอนของเชือก (ด้านตรงข้ามมุม → sin)
✅ ใช้หาแรงสู่ศูนย์กลาง
tanθ = v²/(rg)
หารสมการแนวนอนด้วยแนวดิ่ง: (T·sinθ)/(T·cosθ) = (mv²/r)/(mg)
→ tanθ = v²/(rg)
→ v = √(rg·tanθ)
✅ ใช้หา v จากมุม θ และรัศมี
ω = √(g/(L·cosθ))
แทน r = L·sinθ และ v = rω ในสมการ → ได้ ω ตรงๆ จาก L และ θ
→ T = 2π√(Lcosθ/g)
✅ ใช้หา ω หรือ T โดยไม่ต้องผ่าน v
🔵 Banked Road (ถนนโค้งเอียง)
รถวิ่งบนถนนที่เอียงทำมุม θ กับแนวนอน
แรงที่กระทำ: แรงโน้มถ่วง mg ↓ + แรงปฏิกิริยา N ตั้งฉากผิว
tanθ = v²/(rg)
มุมเอียงที่พอดีสำหรับความเร็ว v และรัศมี r
(ไม่ต้องใช้แรงเสียดทาน เมื่อเดินทางด้วยความเร็วนี้พอดี)
✅ ใช้ออกแบบมุมถนนโค้ง หรือหาความเร็วที่ปลอดภัย
N·cosθ = mg  →  N = mg/cosθ
แรงปฏิกิริยา N ตั้งฉากผิว → ส่วนแนวดิ่ง = N·cosθ = mg
✅ ใช้หาแรงปฏิกิริยาพื้น
N·sinθ = mv²/r
ส่วนแนวนอนของ N = แรงสู่ศูนย์กลาง
✅ ใช้หาแรงสู่ศูนย์กลาง
⬆ วงกลมแนวดิ่ง (ที่จุดสูงสุด/ต่ำสุด)
จุดต่ำสุด: T - mg = mv²/r  →  T = mg + mv²/r
แรงสุทธิขึ้น = แรงสู่ศูนย์กลาง
T ใหญ่ที่สุดที่จุดต่ำสุด (รู้สึกหนักมากตอนก้น)
✅ ใช้หาความตึงเชือกที่จุดล่างสุด
จุดสูงสุด: T + mg = mv²/r  →  T = mv²/r - mg
แรงสุทธิลง = แรงสู่ศูนย์กลาง
T น้อยที่สุดที่จุดสูงสุด ถ้า T = 0 → v_min = √(rg)
✅ ใช้หาความเร็วต่ำสุดที่ยังวิ่งวงกลมได้
📐 เข้าใจ sin และ cos ครั้งเดียวจบ!
หลักง่ายๆ: สามเหลี่ยมมุมฉาก มีด้าน 3 ด้าน
เมื่อกำหนดมุม θ:
sin θ = ด้านตรงข้ามมุม / ด้านตรงข้ามมุมฉาก (ด้านเฉียง)
cos θ = ด้านชิดมุม / ด้านเฉียง
tan θ = sin θ / cos θ = ด้านตรงข้าม / ด้านชิด

จำง่ายๆ:
👉 แนวนอน (x) → cos (ชิด = นอน)
👉 แนวดิ่ง (y) → sin (ตรงข้าม = ตั้ง)

ตัวอย่าง: ถ้าแรง F ทำมุม θ กับแนวนอน
→ ส่วนแนวนอน = F·cosθ
→ ส่วนแนวดิ่ง = F·sinθ

แต่ถ้าทำมุม θ กับแนวดิ่ง (เช่นเชือก):
→ ส่วนแนวนอน = T·sinθ (ตรงข้ามมุม)
→ ส่วนแนวดิ่ง = T·cosθ (ชิดมุม)

⚠ วิธีจำ: ดูว่ามุม θ วัดจากแนวไหน!
มุมวัดจากแนวดิ่ง → ส่วนแนวนอนใช้ sin
มุมวัดจากแนวนอน → ส่วนแนวนอนใช้ cos
(ส่วนที่ "ชิด" มุม → cos, ส่วนที่ "ตรงข้าม" มุม → sin)

ค่าสำคัญที่ต้องจำ:
sin 0° = 0  |  sin 30° = 0.5  |  sin 37° ≈ 0.6  |  sin 45° ≈ 0.707  |  sin 53° ≈ 0.8  |  sin 90° = 1
cos 0° = 1  |  cos 30° ≈ 0.87  |  cos 37° ≈ 0.8  |  cos 45° ≈ 0.707  |  cos 53° ≈ 0.6  |  cos 90° = 0
